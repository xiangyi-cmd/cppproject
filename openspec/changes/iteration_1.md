# OpenSpec 變更紀錄：版本初始化與核心功能實作 (Iteration 1)

本文件紀錄了專案的首次開發迭代流程，從規格確立、程式碼開發到最終功能驗證。

---

## 1. 變更提案與目的 (Proposal)
* **目的**：從零開始建置一個符合期末考題要求的 C++ 智慧型訂房與客房管理系統。
* **規格需求對齊**：
  * [x] C++ 類別繼承與多型 (SingleRoom, DoubleRoom, Suite 繼承自 Room)
  * [x] 檔案讀寫 (讀取與儲存 rooms.csv, bookings.csv)
  * [x] 使用 STL 容器與演算法 (vector, shared_ptr, find_if, sort)
  * [x] 模擬 UI 的終端機互動介面 (ANSI 彩色與健全的防呆輸入)

---

## 2. 實作任務清單與進度 (Tasks)
* [x] **工作 1：專案初始化** - 建立資料夾結構，新增預設資料檔 `rooms.csv`、`bookings.csv`。
* [x] **工作 2：建立物件模型** - 撰寫 `Room.h` 與 `Room.cpp`，定義客房繼承層級。
* [x] **工作 3：實作核心管理器** - 撰寫 `HotelManager.h` 與 `HotelManager.cpp`，使用 STL vector 管理房間，並實現借還書/預訂及統計邏輯。
* [x] **工作 4：實作 CSV 讀寫** - 整合檔案載入與持久化儲存功能。
* [x] **工作 5：完成終端機 UI 與防呆選單** - 撰寫 `main.cpp` 中的防呆輸入常式與主選單迴圈。
* [x] **工作 6：編寫 Windows 一鍵建置指令檔** - 新增 `compile.bat` 與 `run.bat`。

## 3. 測試與驗證結果 (Verification & Test Cases)

我們對編譯完成的 `hotel_system.exe` 執行了以下測試案例：

### 測試案例 3.1：系統資料初始化與載入
* **測試步驟**：啟動 `hotel_system.exe`。
* **預期結果**：終端機輸出「客房資料載入成功！」與「歷史預訂紀錄載入成功！」。
* **實際結果**：與預期完全一致，系統成功從 `rooms.csv` 讀入 101, 102, 103, 201, 202, 301 六間客房。

### 測試案例 3.2：查看客房狀態牆與排序
* **測試步驟**：選擇選單 `1`，接著選擇 `2`（按房價由低到高排序）。
* **預期結果**：顯示包含房號、房型、房價、狀態的彩色表格。房價從低到高排列（1000 元單人房在最上方，5000 元總統套房在最下方）。
* **實際結果**：格式對齊美觀，排序完全正確，未被預訂的客房以綠色顯示 `[空閒]`。

### 測試案例 3.3：防呆輸入驗證
* **測試步驟**：在主選單輸入非數字字元 `abc`，以及超出範圍的數字 `9`。
* **預期結果**：系統應攔截錯誤，提示「請輸入介於 1 到 6 之間的數字！」，且不崩潰、不進入無窮迴圈，重新要求輸入。
* **實際結果**：防呆機制成功運作，緩衝區清理乾淨，系統順利運作。

### 測試案例 3.4：辦理入住與計費多型驗證
* **測試步驟**：
  1. 選擇 `3`，輸入欲預訂房號 `301` (總統套房)。
  2. 輸入住客姓名 `王五`，入住天數 `2` 晚。
* **預期結果**：
  * 顯示預訂成功。
  * 總費用應為：`((基本房價 5000 * 2) + 貴賓室使用費 1000) * 奢侈稅 1.1 = 12100`。
  * 房態牆中 301 號房變為紅色 `[已預訂]`，住客為 `王五 (2 晚)`。
* **實際結果**：計算結果為 $12,100，完全正確，成功展示了 `Suite` 衍生類別的多型計費公式。

### 測試案例 3.5：退房與結帳
* **測試步驟**：選擇 `4`，輸入房號 `301` 辦理退房。
* **預期結果**：印出結帳明細與應付總額 $12100。301 號房重設為 `[空閒]` 狀態。
* **實際結果**：退房成功，房態牆上的 301 房間再次變回綠色的 `[空閒]`。

### 測試案例 3.6：存檔與持久化驗證
* **測試步驟**：預訂 102 房（單人房，3 晚，住客：趙六）後，選擇 `6`（儲存並退出）。查看 `rooms.csv` 與 `bookings.csv`。
* **預期結果**：
  * `rooms.csv` 中的 102 號房該行變為 `102,Single,1000,1,趙六,3`。
  * `bookings.csv` 新增一行訂單資料。
* **實際結果**：兩個 CSV 檔案皆正確寫入並保存了最新狀態，當下次重啟程式時，102 號房成功保持被預訂狀態。
