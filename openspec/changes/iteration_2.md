# OpenSpec 變更紀錄：畫面清屏優化 (Iteration 2)

本文件紀錄了專案的第二次開發迭代流程，主要目標是實作 CMD/終端機的清屏功能，使每次選單操作與返回主畫面時皆能保持畫面乾淨清爽。

---

## 1. 變更提案與目的 (Proposal)
* **目的**：優化終端機使用者體驗。當使用者進入子選單或返回主選單時，清除舊有的輸出資訊，使終端機一次只顯示一個功能畫面的資訊。
* **規格需求對齊**：
  - [x] 建立跨平台清屏功能 `clearScreen()`。
  - [x] 進入主選單前清屏。
  - [x] 進入子選單執行具體功能前清屏。

---

## 2. 實作任務清單與進度 (Tasks)
* [x] **工作 1：在 `main.cpp` 中實作 `clearScreen` 函式**。
* [x] **工作 2：整合清屏呼叫點** - 在主選單迴圈起始處、以及各個 `switch case` 分支起始處加入清屏。
* [x] **工作 3：編譯與驗證** - 執行 `./run.bat` 驗證畫面清理效果與流程流暢度。

---

## 3. 測試與驗證結果 (Verification & Test Cases)

### 測試案例 3.1：主選單載入清屏
* **測試步驟**：啟動 `hotel_system.exe`，完成資料載入後。
* **預期結果**：載入成功的提示字樣被清除，終端機乾淨地呈現「主選單」。
* **實際結果**：執行成功。資料載入提示顯示後，隨即清空畫面並直接顯示乾淨的主選單。

### 測試案例 3.2：子選單操作清屏
* **測試步驟**：在主選單輸入 `1`（查看客房狀態）。
* **預期結果**：主選單畫面被清除，只顯示「查看客房狀態」的排序選擇與房態牆表格。
* **實際結果**：執行成功。進入排序選擇與房態牆展示時，先前的選單內容已全部清空。

### 測試案例 3.3：返回主選單清屏
* **測試步驟**：在客房狀態展示結束後，按下 `Enter` 鍵。
* **預期結果**：舊的房態牆表格被清除，再次呈現乾淨的「主選單」。
* **實際結果**：執行成功。按下 `Enter` 返回時畫面立即清空，乾淨地重新顯示主選單。
