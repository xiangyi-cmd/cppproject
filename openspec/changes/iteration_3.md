# OpenSpec 變更紀錄：方向鍵選單互動優化 (Iteration 3)

本文件紀錄了專案的第三次開發迭代流程，主要目標是將原本以輸入數字為主的選單，全面升級為支援鍵盤上下方向鍵（↑ / ↓）移動高亮、Enter 鍵確定的互動式選單。

---

## 1. 變更提案與目的 (Proposal)
* **目的**：提升終端機 UI 的互動體驗，擺脫傳統繁瑣的數字鍵盤輸入，改以更直覺的方向鍵巡覽選單項目。
* **規格需求對齊**：
  - [x] 引入 `<conio.h>` 及 `_getch()` 來讀取即時鍵盤事件（不需按 Enter 即可觸發）。
  - [x] 實作泛用型方向鍵選單選擇函式 `getMenuChoiceWithArrows`，支援高亮指示符 `=>`。
  - [x] 將「主選單」及所有「子選單選項」（排序、篩選房型、空房篩選）改為方向鍵選擇。
  - [x] 支援跨平台降級（非 Windows 系統自動降級為傳統數字輸入以避免編譯失敗）。

---

## 2. 實作任務清單與進度 (Tasks)
* [x] **工作 1：實作 `getMenuChoiceWithArrows` 函式**。
* [x] **工作 2：改寫 `main.cpp` 中的主選單與子功能選單** - 使用新函式替換原本的 `getValidIntInput`。
* [x] **工作 3：編譯與驗證** - 執行編譯並手動操作選單，確保方向鍵巡覽順暢、Enter 鍵響應正確。

---

## 3. 測試與驗證結果 (Verification & Test Cases)

### 測試案例 3.1：主選單方向鍵巡覽
* **測試步驟**：啟動系統，按下 `↓` 鍵三次，再按下 `↑` 鍵一次。
* **預期結果**：高亮指標 `=>` 應順暢移動。按下 `↓` 往下移動，按下 `↑` 往上移動。
* **實際結果**：執行成功。指標 `=>` 與青色高亮均能順暢地隨著鍵盤 Up / Down 鍵上下移動，且選單首尾具有循環移動效果。

### 測試案例 3.2：選單選取確認
* **測試步驟**：在主選單將高亮移動到「5. 查看飯店營運統計 (View Statistics)」，按 `Enter` 鍵。
* **預期結果**：成功進入營運統計畫面。
* **實際結果**：執行成功。按下 `Enter` 鍵後，畫面立即清屏，隨即輸出營運統計數據，流程流暢且精準。

### 測試案例 3.3：子選單方向鍵整合
* **測試步驟**：在主選單進入「1. 查看所有客房狀態」，驗證排序方式選擇是否也能用方向鍵選取。
* **預期結果**：排序選擇選單也能使用方向鍵高亮巡覽。
* **實際結果**：執行成功。查看房間狀態的排序選擇已成功整合方向鍵與高亮功能，可正常以 ↑/↓ 鍵選擇排序規則。
